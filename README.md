# A working amount in rupees distinguisher
<br>
A program that breaks down a total amount into its corresponding 500, 200, 100, 50, 20, 10, 5, 2, and 1 rupee notes. It helps divide money into various denominations, which is especially useful for small businesses.
<br> 
After downloading the folder you can double click on the RunTheCode file to run it in the file explorer
